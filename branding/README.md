# IP Bot 品牌素材

名称：IP Bot。

Logo 以圆角对话气泡与两点机器人眼睛组合，顶部单点天线表达智能助手。采用平面几何，便于小尺寸识别。

- 蓝色：`#74ADFF`
- 深蓝：`#123A75`
- `ip-bot-logo.svg`：可编辑矢量图标
- `ip-bot-logo.png`：1024px 透明圆角图标
- `logo.png`：1024px 贴牌脚本源图
- `ip-bot-wordmark.svg`：浅色背景横版字标
- `ip-bot-wordmark-dark.svg`：深色背景横版字标

界面 Logo、Windows/macOS 应用图标、托盘图标已替换。内部包名及数据标识保留，避免影响已有数据与配置路径。
